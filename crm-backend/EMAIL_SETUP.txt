Correo de bienvenida
====================

El backend envía el correo mediante la API HTTPS de Brevo (puerto 443), no
mediante SMTP. No es necesario configurar un puerto SMTP ni credenciales SMTP.

- BREVO_API_KEY: clave API de Brevo. Se crea desde Configuración de la cuenta
  > SMTP & API > API keys. No uses una clave SMTP.
- BREVO_FROM_EMAIL: dirección remitente verificada en Brevo.
- BREVO_FROM_NAME: nombre visible del remitente (opcional; por defecto
  "La Nueva Ideal").
- FRONTEND_LOGIN_URL: URL HTTPS de inicio de sesión. Por defecto:
  https://weblanuevaideal.web.app/?login=1

Guarda estas variables en el entorno del backend (por ejemplo, en Render), no
en el repositorio. Brevo requiere que el remitente esté verificado. El envío
también requiere un perfil de usuario ya creado en Firestore.
